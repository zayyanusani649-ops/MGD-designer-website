MGD DESIGNER WEBSITE
====================

1. Open index.html in a browser to preview the website.
2. Keep the assets folder next to index.html.
3. Before publishing, edit index.html and replace the # in the "Contact me on Fiverr" button with your real Fiverr profile URL.
4. The portfolio section currently shows the graphic design samples supplied for this project.
5. HTML website development and Microsoft Word are listed as services, but are not presented as completed portfolio samples.

The website uses plain HTML, CSS and a tiny JavaScript snippet. No frameworks or paid tools are required.
